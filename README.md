# expenses_bot 

Бот для учёта семейных расходов. Пишешь в Telegram трату, и он сам разберётся, сколько потрачено, на что и когда. Глава семьи смотрит и правит траты всех членов семьи в веб-админке.

## Что умеет

**Бот** понимает обычный текст, без кнопок и команд:

- `кофе 350`, `такси 1200 вчера` — добавить трату
- `сколько потратил на еду в этом месяце`, `покажи траты за неделю` — посмотреть траты и итог
- `последнее было не 350, а 450` — исправить
- `удали такси` — удалить

Каждый видит и меняет только свои траты.

**Админка** открывается на http://localhost:8080. Там траты всей семьи с фильтрами по члену семьи, периоду и категории, а ещё добавление, редактирование и удаление. Авторизации нет, поэтому админка слушает только localhost и отбивает запросы с чужих сайтов.

## Как это работает

```
Telegram ──► бот ──► ИИ-агент (OpenRouter) ──► что хотел сказать пользователь
                └──────────────► Postgres ◄────── REST API ◄── админка
```

- **ИИ-агент** (`agent/`) отправляет фразу в LLM и получает обратно JSON: действие, сумму, категорию, даты. Бот проверяет ответ и выполняет его. Используются бесплатные модели OpenRouter: при запуске агент сам подбирает подходящие из каталога. Бесплатные модели иногда падают или отвечают ерундой, поэтому агент повторяет запрос, и у основной модели есть две запасные.
- **Бот** (`internal/bot/`) ходит в Telegram Bot API напрямую через long polling, без сторонних библиотек.
- **REST API** (`internal/handler/`): `GET/POST /api/expenses`, `PUT/DELETE /api/expenses/{id}`.
- **Админка** (`web/`) — один HTML-файл на чистом JS. Он вшит прямо в бинарник.
- **База** — Postgres. Миграция (`migrations/`) накатывается при старте. Приложение подключается к базе отдельным пользователем без прав суперпользователя, этого пользователя создаёт `init-db`.

## Запуск

Понадобятся токен бота от [@BotFather](https://t.me/BotFather) и ключ [OpenRouter](https://openrouter.ai/keys).

### С Docker
```bash
cp .env.example .env
# вписать BOT_TOKEN, LLM_API_KEY и пароли DB_ADMIN_PASSWORD / DB_PASSWORD
docker compose up -d --build   # или make up
```

Пиши боту, админка на http://localhost:8080.

Логи смотреть через `make logs`, остановить всё через `make down`.

После изменений в `.env`
```
docker compose up для //для просмотра логов в терминале, иначе как демон с флагом (-d)
```

### Без Docker

Нужны Go 1.25+ и локальный Postgres. В `.env` указать `DB_ADMIN_*` от своего суперпользователя Postgres и:

```bash
make run
```

## Настройки

Все настройки лежат в `.env`, пример в `.env.example`.

| Переменная | Что это                                                                             |
|---|-------------------------------------------------------------------------------------|
| `BOT_TOKEN` | токен Telegram-бота. Если пусто, бот не стартует, но админка работает               |
| `LLM_API_KEY` | ключ OpenRouter                                                                     |
| `LLM_MODEL` | `auto` — подбор бесплатных моделей при старте. Можно перечислить свои через запятую |
| `LLM_BASE_URL` | любой OpenAI-совместимый API: OpenRouter, Groq, Ollama                              |
| `TZ` | часовой пояс, от него считаются «вчера» и «в этом месяце»                           |


## Что по-хорошему доделать


- **Пускать в бота только членов семьи.** Сейчас писать боту может любой, кто его найдёт: его траты попадут в семейную админку, а запросы съедят лимит бесплатных моделей. Можно сделать списком разрешённых Telegram ID в `.env`.
- **Отдельный пользователь для миграций.** Сейчас приложение владеет базой и может менять схему. Лучше, чтобы пользователь умел только `SELECT/INSERT/UPDATE/DELETE`.
